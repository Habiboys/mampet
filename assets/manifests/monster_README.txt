FOODDEX 2D MONSTER COLLECTION — FLUTTER ASSETS

20 species × 3 phases = 60 transparent 1024×1024 PNG files.
Assets paths: assets/monsters/<species>/<baby|young|adult>.png
All monster images are static. Animate idle floating in Flutter using AnimationController, Transform.translate, or TweenAnimationBuilder.
Add the line below to pubspec.yaml under flutter/assets:
  - assets/monsters/

Some source art was generated on shared illustrated sheets then cropped into individual transparent canvases. Check the final appearance at your target UI size before release.
